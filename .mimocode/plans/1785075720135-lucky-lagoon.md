# Analyse du projet — apiPlayground (Reqly)

## Vision générale

**Reqly** est une plateforme de test API complète — une alternative open-source à Postman/Bruno — avec 4 surfaces d'interaction :

| Surface                      | Technologie                       | Rôle                                                            |
| ---------------------------- | --------------------------------- | --------------------------------------------------------------- |
| **Web UI** (`reqy-web`)      | Next.js 16 (React 19, TypeScript) | Interface utilisateur principale                                |
| **Desktop** (`src-tauri`)    | Tauri 2 + Rust                    | Wrapper bureau avec features système (proxy, Git, MCP, offline) |
| **CLI** (`recli`)            | Node.js + Commander               | Tests API en ligne de commande (CI/CD, scripting)               |
| **Serveur MCP** (`reqy-mcp`) | Node.js + MCP SDK                 | Expose les collections aux agents IA                            |

Le projet inclut aussi :

- **Sync Server** (`sync-server`) : backend Hono + SQLite pour la synchronisation multi-utilisateur
- **Package partagé** (`packages/shared`) : moteur d'assertions, parseur curl, OpenAPI

## Fonctionnalités clés

### 1. Testeur d'API HTTP

- Support : GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS, GRAPHQL
- Éditeur de requête complet (headers, body, auth, params)
- Visualisation des réponses (JSON, XML, HTML, image, binaire)
- Codegen (curl, fetch, axios, etc.)
- Historique des requêtes
- Cookies manager
- SSL toggle (certificats auto-signés)
- Variables d'environnement et chaînage

### 2. Gestion des collections

- Organisation arborescente (dossiers + requêtes)
- Import : Postman, Bruno, OpenAPI, cURL
- Export : Postman, OpenAPI, cURL, JUnit
- Snapshots de réponses
- Tests et assertions
- Scripts pre-request / post-response

### 3. Clients spécialisés

- **GraphQL** : éditeur avec schema introspection, autocomplétion
- **WebSocket** : client temps réel
- **SSE** : client Server-Sent Events
- **gRPC** : via Rust + Tauri

### 4. Intelligence Artificielle

- **AI Sidebar** : assistant IA contextuel (sidepanel droit, 400px, resizable)
- **Actions IA** : exécution de requêtes, CRUD collections, analyse de réponses
- **Generate request from description** : description texte → requête HTTP
- **Project analyzer** : détection de routes dans un projet (7 frameworks)
- **AI Insights** : analyse intelligente des réponses
- Contexte de page automatique (via `useAiContext`)

### 5. Capture HTTP

- Proxy de capture (tiny_http) avec throttling configurable
- Sessions capturées persistées
- Capture-to-Test (transformer une capture en requête de test)

### 6. Intégration Git

- 25 commandes Tauri (git2 natif Rust)
- Init, clone, status, diff, commit, branches, remotes, push/pull/fetch
- Sync collections ↔ fichiers Git

### 7. Mode hors-ligne

- File d'attente offline persistée (FIFO)
- Permet d'envoyer des requêtes même déconnecté, rejeu automatique

### 8. Synchronisation

- Serveur Hono + SQLite (better-sqlite3)
- Auth par email/mot de passe avec vérification
- Workspaces multi-utilisateurs
- Sync en temps réel via WebSocket
- Détection de conflits (last-writer-wins)

### 9. CLI (recli)

- 10 commandes : run, graphql, validate, init, export, watch, diff, openapi, ui
- Exécution parallèle (jusqu'à 20 workers)
- Scripting sandboxé (vm.createContext)
- Assertions (texte, JSON Schema)
- Snapshots testing
- Data-driven (CSV/JSON)
- Rapports : CLI coloré, JSON, JUnit XML, HTML
- Cookie Jar automatique

### 10. MCP Server (42 outils)

- Collections (6), Requêtes (9), Exécution (5)
- Assertions & historique (3), Dossiers (3)
- Environnements (7), Import/Export (7), IA (2)
- Protection SSRF, limite de taille, timeout

## Stack technique

### Frontend

- **Framework** : Next.js 16 (App Router)
- **UI** : React 19, TypeScript 5.7, Tailwind CSS 4
- **State** : Zustand 5 (stores persistés)
- **Composants** : Radix UI, shadcn/ui, Lucide icons
- **Édition** : CodeMirror 6, GraphiQL
- **Formulaires** : React Hook Form + Zod
- **Resizable** : react-resizable-panels
- **Stockage** : IndexedDB (idb-keyval)
- **Persistence** : système custom avec migration localStorage → IDB
- **Tests** : Vitest, Playwright, Testing Library

### Backend (sync-server)

- **Runtime** : Node.js (Hono)
- **DB** : SQLite (better-sqlite3)
- **Auth** : HMAC-SHA256 (sessions signées)
- **Email** : SMTP / Resend / Log
- **Temps réel** : WebSocket
- **Rate limiting** : fenêtre glissante mémoire

### Desktop (Tauri)

- **Rust** : édition 2024
- **TLS** : Rustls (ring)
- **HTTP** : reqwest
- **Git** : git2 (libgit2)
- **Capture** : tiny_http
- **IPC** : Tauri commands + events

### CLI (recli)

- **Runtime** : Node.js ≥ 18
- **CLI** : Commander.js
- **HTTP** : fetch natif (zéro dépendance)
- **Tests** : Vitest (103 tests)
